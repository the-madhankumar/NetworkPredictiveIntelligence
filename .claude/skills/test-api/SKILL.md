# Test API

Run the project's API/backend test suite.

Inspect the repository first to determine the correct test command.

Do not modify application code while running this command.

Return:

## STATUS

PASS or FAIL

## TESTS RUN

List the command and test scope.

## FAILURES

List each failing test with its likely cause.

## API CONTRACT IMPACT

State whether any failure appears related to an API contract.

## NEXT CHECKS

List the next useful investigation steps.
